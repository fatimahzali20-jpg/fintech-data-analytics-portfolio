Excel Financial Analysis


Overview

This project demonstrates my use of Microsoft Excel to analyse and summarise a sample financial dataset.

The workbook contains practical examples of data analysis using VLOOKUP, PivotTables and PivotCharts.

Skills Demonstrated

- Microsoft Excel
- VLOOKUP
- PivotTables
- PivotCharts
- Data analysis
- Financial data analysis
- Data summarisation and visualisation

VLOOKUP Analysis

I used VLOOKUP to retrieve financial information for individual companies from the cleaned financial dataset.

The lookup exercise retrieves information including:

- Revenue
- Sector
- Profit

This demonstrates my ability to use lookup functions to retrieve information from structured datasets.

PivotTable Analysis

I created a PivotTable to summarise total revenue by sector.

The analysis allows financial performance across sectors to be compared without manually calculating individual totals.

The sectors analysed include:

- Technology
- Banking
- Automotive

Data Visualisation

I created a PivotChart from the PivotTable to visually compare revenue across sectors.

This provides a clearer representation of the financial data and makes differences between sectors easier to identify.

Project Purpose

The purpose of this project was to demonstrate practical Excel skills that can be applied to financial and business datasets.

It complements my wider portfolio work involving Python, Pandas, SQL and financial data analysis.
