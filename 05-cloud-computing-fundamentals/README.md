# Cloud Computing Fundamentals

## Overview

This section demonstrates my foundational understanding of cloud computing concepts developed through university study in Business Computing.

My learning covered cloud service models, cloud economics, large-scale data processing and the relationship between cloud technologies and modern data analytics.

## Cloud Service Models

I developed an understanding of the main cloud service models:

- **SaaS** – applications and software delivered as a service.
- **IaaS** – computing infrastructure delivered through cloud services.
- **PaaS** – platforms that support application development and deployment.

I also studied the economic principles of cloud computing, including pay-as-you-go resource usage and the potential effects of over-provisioning and under-provisioning computing resources.

## Cloud Computing and Data Analytics

My studies also introduced the relationship between cloud computing and large-scale data analysis.

This included concepts such as distributed computing, data warehousing, MapReduce, Hadoop and Hive.

I developed an introductory understanding of how MapReduce divides large-scale data processing into mapping and aggregation stages and how technologies such as Hive can provide SQL-like querying for large datasets.

## Relationship to FinTech and Data Analytics

Cloud computing is particularly relevant to my wider development in FinTech and Data Analytics because modern financial organisations can generate large quantities of transactional, market and customer data.

Understanding cloud and large-scale data processing concepts provides useful context for how data can be stored, processed and analysed at scale.

## Skill Level

My current cloud computing knowledge is foundational and primarily based on academic study.

This evidence demonstrates conceptual understanding rather than professional cloud infrastructure deployment experience.
