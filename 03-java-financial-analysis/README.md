Java Financial Performance Analysis

Overview

This project demonstrates my foundational Java programming skills through a simple financial performance analysis program.

The program uses sample company revenue and cost data to calculate profit and profit margin, before categorising each company's financial performance.

Skills Demonstrated

- Java fundamentals
- Variables and data types
- Arrays
- For loops
- Conditional statements
- Arithmetic calculations
- Console output
- Basic financial analysis

How the Program Works

The program stores sample company names, revenue figures and costs using arrays.

A `for` loop processes each company and calculates:

- Profit
- Profit margin
- Performance category

The performance category is determined using `if`, `else if` and `else` conditional statements.

Companies are classified as:

- High performance: profit margin of 35% or above
- Medium performance: profit margin of 25% to below 35%
- Low performance: profit margin below 25%

Example Analysis

The program analyses sample data for:

- Apple
- Microsoft
- Tesla
- Barclays

For each company, the program outputs its revenue, calculated profit, profit margin and performance category.

Project Purpose

The purpose of this project was to apply introductory Java programming concepts to a simple financial analysis scenario.

This project demonstrates my foundational understanding of Java syntax, loops, conditional logic, arrays, data types and calculations.
