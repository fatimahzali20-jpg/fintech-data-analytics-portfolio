GDPR Data Handling Assessment

Overview

This project demonstrates my foundational understanding of GDPR principles and their application to financial and customer data.

I produced a data handling assessment based on a scenario involving a financial services company holding customer information such as names, email addresses, account numbers, transaction values and dates.

Skills and Knowledge Demonstrated

- GDPR fundamentals
- Personal data identification
- Data minimisation
- Purpose limitation
- Data security and confidentiality
- Data retention
- Data subject rights
- Personal data breach awareness
- Application of GDPR principles to financial data

Scenario

The assessment considers how a financial services organisation should handle a customer dataset containing identifiable personal and financial information.

I considered the GDPR implications of collecting, storing, accessing, analysing and retaining this information.

Areas Considered

The assessment covers:

- Identification of personal data
- Lawfulness, fairness and transparency
- Purpose limitation
- Data minimisation
- Accuracy
- Storage limitation
- Integrity and confidentiality
- Access controls
- Pseudonymisation where appropriate
- Secure data storage and sharing
- Data retention and deletion
- Data subject rights
- Personal data breach reporting

## Purpose

The purpose of this project was to demonstrate how foundational GDPR principles can be applied to a realistic financial data-handling scenario.

The project complements my technical data analytics skills by demonstrating awareness of the responsibilities involved when working with personal and financial data.
